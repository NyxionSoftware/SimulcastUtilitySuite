# Simulcast Utility Wiki

Welcome to the Simulcast Utility documentation.

Simulcast Utility is a Windows application for discovering, configuring, monitoring, and controlling compatible broadcast receivers. Its plugin system can add schedules, media, themes, settings, commands, and interface elements without modifying the main application.
