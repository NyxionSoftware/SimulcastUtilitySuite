# Managing Receivers

Open **Manage Receivers** from the main toolbar.

## Add a receiver

1. Select **Add Receiver**.
2. Enter a non-empty display name.
3. Enter the numeric receiver ID.
4. Enter a valid four-octet IPv4 address.
5. Select **Save Receiver**.

The receiver must be discovered successfully before it is added. Discovery also verifies that the receiver ID belongs to the specified IP address.

## Edit a receiver

Select a configured receiver, update its fields, and select **Save Receiver**. Save is enabled only when the fields are valid and differ from the saved configuration.

While a receiver is being edited, its virtual remote controls are disabled. Open remote windows begin using the saved receiver information when editing completes.

## Delete a receiver

Select the receiver and choose **Delete**. Confirm the deletion in the modal prompt. Deletion takes effect immediately.

## Reorder receivers

Drag a receiver to its new position. Other receivers animate around the insertion point, and the new order is saved immediately.

## Leave without saving

Use the back button. If the selected receiver has unsaved changes, Simulcast Utility asks whether those changes should be discarded.

## Status colors

- Green indicates an online or successful state.
- Red indicates an offline or failed state.
- Yellow indicates a transitional or warning state.

The activity badge reports operations such as discovery, refreshing, editing, or transmitting commands.
