# Using the Virtual Remote

Select a receiver and choose **Virtual Remote**. Remote windows are modeless, so the main application remains usable.

Only one remote window can be open for each receiver. Selecting Virtual Remote again focuses the existing window.

## Channel entry

- Number buttons build a channel number in the display.
- Channel numbers must resolve to channels 1 through 50.
- Valid channels are normalized to the receiver's three-digit format.
- Press **OK** to send the entered channel immediately.
- An incomplete channel entry clears after eight seconds.

The OK button displays green feedback for a valid channel and red feedback for an invalid channel. Invalid entries are cleared.

## Menu behavior

The Menu action sends two consecutive `BACK` key presses.

## Activity badge

The activity badge displays when the remote is transmitting and returns to idle when the command finishes. Controls are disabled while the receiver is being edited.
